# Testing

This directory contains tests for the Remote Patient Vital Signs Monitoring System.

## Testing Responsibilities

- REST API testing
- Authentication and authorization testing
- Input validation and error handling
- WebSocket integration testing
- Vital data ingestion testing
- Alert acknowledgement and escalation testing
- Device offline and missing-data scenarios
- End-to-end and regression testing

## Testing Guidelines

- Follow the Master API Specification.
- Test features incrementally as they become available.
- Record bugs with reproduction steps and expected versus actual results.
- Do not treat unimplemented features as failed tests; mark them as pending.
