# AI-Enabled Real-Time Remote Patient Vital Signs Monitoring System with Early-Warning Alerts

## Project Overview

This is a B.Tech CSE final-year project focused on real-time remote patient vital-sign monitoring and early-warning alerts.

## Core Features

- Patient registration and profile management
- Real-time heart rate, SpO₂ and ECG monitoring
- MQTT-based device communication
- Patient database and health history
- Rule-based alerts and notifications
- AI-based health risk and trend prediction
- Digital Health Passport
- Historical health analytics and reports
- Authentication and authorization

## Technology Stack

- Frontend: React
- Backend: FastAPI
- Database: PostgreSQL
- ORM: SQLAlchemy
- IoT communication: MQTT
- Real-time updates: WebSockets

## Development Guidelines

- Follow the Master API Specification and Team Development Plan.
- Keep code simple, modular, readable and maintainable.
- Do not change API contracts or database fields without team agreement.
- Test features incrementally during development.
- AI outputs indicate health risks and trends; they are not medical diagnoses.
