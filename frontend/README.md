# Frontend

This directory contains the React frontend for the Remote Patient Vital Signs Monitoring System.

## Responsibilities

- Login and authentication UI
- Multi-patient dashboard
- Patient registration and profile pages
- Live vital-sign and ECG monitoring
- Alerts and acknowledgement UI
- AI risk and trend visualization
- Digital Health Passport
- Analytics and reports
- REST API and WebSocket integration

## Development Rules

Follow the Master API Specification. Use the agreed backend API contracts and shared UI components. Do not invent endpoints or silently change API requirements.
