# Backend

This directory contains the FastAPI backend and database implementation for the Remote Patient Vital Signs Monitoring System.

## Responsibilities

- REST APIs
- PostgreSQL database and SQLAlchemy models
- Authentication and authorization
- MQTT data ingestion and validation
- Vital-sign and ECG data storage
- Rule-based alerts and notifications
- AI risk/trend backend integration
- Patient history and report APIs

## Development Rules

Follow the Master API Specification. Keep modules simple, readable and modular. Agree on API and database changes with the team before implementation.
